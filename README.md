# Climate System Laboratory, Seoul National University

서울대학교 지구환경과학부 기후시스템연구실(국종성 교수) 홈페이지의 원본 저장소입니다.

- 사이트: https://climate.snu.ac.kr (GitHub Pages, `snu-climate.github.io`는 이 주소로 넘어감)
- 구조: `data/`(YAML) · `content/news/`(뉴스) · `static/`(사진·그림) · `themes/`(디자인) · `scripts/`(빌드·검증)
- 배포: `main`에 반영되면 GitHub Actions가 `t5.v02` 테마를 빌드·검증해 GitHub Pages로 배포합니다.

내용을 고치거나 추가하려면 [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요.
운영 방법(관리자, 리뷰·사진 받는 법, 정기 점검)은 [HANDOVER.md](HANDOVER.md)에 있습니다.
