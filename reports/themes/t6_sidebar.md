# t6_sidebar — Sidebar Portfolio

## 결과
- 빌드 성공(24쪽: EN 8 + KO 8 + 뉴스 상세 4×2), validate **오류 0**. 경고 2건은 데이터 쪽(placeholder 8건, 숨긴 논문 1건)이고 테마와 무관.
- 스크린샷: `site/_shots/t6_sidebar.png`, `site/_shots/t6_sidebar_mobile.png`
- 파일: `themes/t6_sidebar/{theme.yaml, templates/(base, ui, 9개 페이지).html, assets/style.css}`

## 디자인 요약
- al-folio 계열의 학술 포트폴리오다.
  - 1000px 이상: 왼쪽 고정 사이드바 280px(로고, 연구실명·소속, 아이콘 메뉴와 현재 페이지 강조 막대, English/한국어 분할 토글, 연락처, 소셜 아이콘)와 오른쪽 본문(최대 860px).
  - 1000px 미만: 상단 sticky 바(로고, 연구실명, EN/KO 버튼, 햄버거)로 바뀐다. 햄버거를 누르면 메뉴·언어·연락처 패널이 펼쳐진다(`data-nav-toggle` → `#sb-panel[data-open]`).
- 색: 청록 포인트(#0b6a8a, 다크 #5cc0e2)와 흰 바탕/다크 #121417. 글꼴은 Roboto + Roboto Slab(제목) + Pretendard(한글).
- 홈은 PI 중심이다.
  - 이름(성 앞부분 굵게)과 직함·소속, 오른쪽에 떠 있는 사진 자리. 사진 자리는 청록 그라디언트에 등압선 같은 동심 타원과 이니셜을 그렸고, `pi.photo`를 넣으면 사진으로 바뀐다.
  - 소개문, 연구 관심사 칩, 뉴스 표(날짜 | 제목 + 분류), 대표 논문(`selected_pubs`, 없으면 featured → 최근 순으로 대체), 연구 분야 미니 카드, 영상, Join us 안내.
- 논문 목록(al-folio bibliography):
  - 왼쪽에 학술지 약칭 배지(`<abbr title="전체 이름">`)와 번호 `[p.num]`, 오른쪽에 제목(DOI 링크), 저자(구성원 굵게 + 밑줄), 서지사항, DOI·CA·Featured 칩.
  - 연도 제목은 오른쪽 정렬로 크게 넣었다. 검색창과 연도 알약(편수 표시)이 있고, 모바일에서 연도 알약은 가로 스크롤 한 줄이다.
- 학술지 배지:
  - `ui.html`에 약칭 표를 두었다(현재 데이터의 학술지 45종 전부 + 자주 쓰는 기후 학술지).
  - 표에 없는 학술지는 단어 머리글자로 자동 약칭한다.
  - 색은 출판사 계열로 나눈다: Nature, Science/PNAS, AGU, AMS, Springer, IOP, Elsevier, 기타. 모두 흰 글자 대비 4.5:1 이상.
- 연구: 주제마다 그라디언트 타일(위경도 격자 + 물결선 + `research[].regions` 실제 좌표 점, 캡션 "Key study regions")과 번호·제목·요약을 두고, 그 아래에 주요 논문(배지)과 관련 영상을 둔다.
- 구성원: PI 카드(원형 사진 자리, 역할, 연락처), 소개, CV 카드 3개(연도 배지 + 내용), 역할별 프로필 카드(그라디언트 원형 이니셜), 졸업생 표.
- 뉴스: 가로 카드(텍스트 + 표지, 표지가 없으면 그라디언트 + 아이콘). 상세는 제목, 날짜·분류, 요약 인용선, 본문, 연결 논문 상자, 이전/다음 글.

## 남은 문제
- 웹폰트는 CDN에 의존한다(실패하면 시스템 글꼴로 대체).
- `--full` 전체 길이 스크린샷에서는 고정 사이드바가 첫 화면 높이까지만 찍힌다. Playwright가 fixed 요소를 그렇게 찍기 때문이고, 실제 브라우저에서는 정상이다.
- 학술지 약칭 표는 테마 템플릿 안에 있다. 새 학술지는 머리글자 약칭으로 자동 처리되지만, 정확한 약칭을 원하면 표에 한 줄 추가해야 한다(아래 공통 제안 참고).

## 테마 안에서 직접 처리한 문구(i18n.yaml 추가 제안)
| 제안 키 | en | ko |
|---|---|---|
| `common.skip` | Skip to content | 본문 바로가기 |
| `pubs.years` | Years | 연도 |
| `research.regions` | Key study regions | 주요 연구 지역 |
| `news.prev` / `news.next` | Previous / Next | 이전 글 / 다음 글 |

## 공통 코드 제안(수정하지 않음)
1. **학술지 약칭을 데이터로**: `data/journals.yaml`(이름 → 약칭·출판사)을 두거나 build.py에서 `p.journal_abbr`를 계산해 주면, 배지·약칭을 쓰는 다른 테마(t4 주요 학술지 막대 등)도 같은 값을 쓸 수 있다.
2. `scripts/shot.mjs --full`: lazy 이미지가 로드되도록 캡처 전에 스크롤하자(영상 썸네일이 검게 찍힌다).
3. `macros.news_body`의 연결 논문 `pub_item`에 `anchor=False` 옵션을 주자(뉴스 페이지에 불필요한 `id="pub-N"`과 `data-pub-item`이 붙는다).
4. `shared.js` 메뉴 토글에 Esc로 닫기, 메뉴 링크를 누르면 닫기 기능을 추가하자.
