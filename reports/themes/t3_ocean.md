  - 아래쪽 파도: 세 겹이 30~64초 주기로 흐르고, 맨 앞 파도를 페이지 배경색으로 칠해 본문과 이어지게 했다.

- **이니셜**: 테마 매크로 `o.ini()`가 한글 이름이면 첫 글자(성, 예: "국"), 영문이면 머리글자 2개(예: "JK")를 쓴다. 구성원 카드는 이 규칙을 쓰려고 `o.member_card`(공통 매크로와 같은 마크업)를 쓴다.

고친 것:
- 파도 SVG가 `max-width:100%`에 잘려 생기던 끊김
- 모바일에서 헤더 버튼이 줄바꿈되던 문제
- 연구 페이지 그라디언트 id에 공백이 들어가 검게 나오던 문제
- 논문 페이지 모바일 34px 넘침
- 논문이 317편으로 늘어 연도 목록이 길어진 문제

## 남은 문제
- `backdrop-filter`가 많아서 저사양 모바일에서는 스크롤이 무거울 수 있다. 문제가 되면 `.glass`의 blur 값만 줄이면 된다.
- 홈 모바일 히어로는 `100svh`에 세로 가운데 정렬이라, 키 큰 화면에서는 위쪽 여백이 크다.
- 전체 페이지 스크린샷에서는 `loading="lazy"` 이미지(영상 썸네일)가 검게 찍힌다. 브라우저에서는 스크롤하면 정상으로 로드된다.
- 테마 고유 문구를 템플릿 안에서 처리함 → i18n.yaml 추가 제안:
  - `common.skip`: Skip to content / 본문 바로가기
  - `common.links`: Links / 바로가기
  - `home.scroll`: Scroll down / 아래로 이동

## 공통 코드 제안(고치지 않음)
1. `macros.html`의 `initials_of`: 한글 이름에서 앞 두 글자를 잘라 "예시 구성원 A" → "예구", "홍길동" → "홍길"이 된다. 한글이면 첫 글자만 쓰도록 바꾸는 것을 제안한다(두 테마에는 같은 규칙의 테마 매크로를 넣음).
2. `m.pub_item`이 항상 `id="pub-N"`을 넣는다. 같은 논문이 연구 페이지의 여러 주제에 걸리면 id가 중복될 수 있다. `pub_item(p, anchor=False)` 옵션을 제안한다.
3. 데이터: 제목 3건이 `CO <sub>2</sub>`처럼 아래첨자 앞에 공백이 있어 "CO ₂"로 보인다(`data/publications.yaml` 72, 91, 281행 부근). Crossref에서 받은 원문 그대로이므로 `add_publication.py`에서 `\s+<sub>` → `<sub>` 정리를 제안한다.
4. `scripts/shot.mjs --full`: 캡처 전에 lazy 이미지를 eager로 바꾸거나 끝까지 스크롤하면 검토용 풀페이지 캡처가 정확해진다.
