# t7_onepage — One-page Scroll

## 결과
- 빌드 성공(24쪽: EN 8 + KO 8 + 뉴스 상세 4×2), `validate --theme t7_onepage` **오류 0**
  - 경고 2건은 모두 데이터 쪽: placeholder 8건, 숨긴 논문 1건
- 스크린샷: `site/_shots/t7_onepage.png`, `t7_onepage_mobile.png` (+ `_full`, `_publications`)
- 360px 폭 가로 넘침: EN/KO 16개 페이지 × 라이트/다크 검사, 모두 0px

## 디자인 요약
- **구성**: `index.html` 한 페이지에 섹션 8개를 둔다. 순서와 번호는 `site.nav`를 따른다.
  - `#top` 히어로
  - `#research` 연구
  - `#people` 구성원
  - `#publications` 최근 논문 10편 + "전체 보기 · N편"
  - `#presentations` 발표
  - `#news` 뉴스
  - `#videos` 영상 + 채널 링크
  - `#contact` 연락처(반전 색 띠)
- **스티키 섹션 바 + 스크롤 스파이**: 테마 JS(`assets/onepage.js`, IntersectionObserver)가 맡는다.
  - 홈에서는 바의 링크가 `#섹션`을 가리킨다. 화면 38~42% 높이의 기준선을 지나는 섹션을 현재 위치로 보고 `aria-current="location"`을 단다.
  - 짧은 마지막 섹션은 페이지 끝에 닿으면 현재 위치로 표시한다.
  - 모바일에서는 바가 두 번째 줄의 가로 스크롤 칩(높이 44px)이 되고, 현재 칩이 자동으로 보이게 스크롤된다.
  - 데스크톱(1240px 이상)에서는 한 줄 메뉴가 된다.
- **전체 메뉴(sheet)**: 규약의 `data-nav-toggle` 버튼(48px)을 누르면 전체 화면 메뉴가 열린다.
  - 번호가 붙은 64px 높이의 큰 항목과 이메일·전화 버튼이 있다.
  - 링크를 누르거나 Esc를 누르면 닫힌다(테마 JS). 열려 있는 동안 본문 스크롤을 잠근다.
- **상세 페이지**: 같은 스타일의 상단 머리를 쓴다.
  - 브레드크럼 "← 홈 / 0N 섹션"이 `index.html#<섹션>`로 연결된다. 이 링크들이 실제 id와 일치함을 validate로 확인했다.
  - 상세 페이지의 바·메뉴는 각 상세 페이지로 연결되고, 현재 페이지에 `aria-current="page"`가 붙는다.
  - 논문 상세: 연도 칩 바가 sticky로 붙고, 같은 스크롤 스파이로 현재 연도를 표시한다. 모바일은 가로 스크롤, 데스크톱은 줄바꿈. 검색, 연도 섹션, `p.num`은 그대로 유지했다.
- **히어로**
  - 큰 연구실명(Space Grotesk), 형광펜 강조 태그라인, 소개문, CTA 2개
  - 오른쪽 "이 페이지의 구성" 목차 카드: 섹션 번호 + 개수(연구 분야, 논문, 발표, 뉴스, 영상 — 실제 데이터). 모바일에서는 2열 타일이 된다.
- **팔레트**: 종이색 `#f7f5f0` + 잉크 `#15171c` + 코발트 `#2340c8` + 앰버 `#ffb43d`. 연구 카드는 주제별 색 띠 5색. 다크 모드도 지원한다.
- **이미지 대체물**
  - PI: 코발트 사각 이니셜("JK"/"국")
  - 구성원: 이니셜 칩(한글 이름이면 성 한 글자)
  - 커버 없는 뉴스: 코발트→보라 그라디언트 + 점 패턴 + "CSL"
- **대비**(계산값)
  - muted 6.4:1, 링크 7.3:1, 다크 muted 8.5:1
  - 교신저자 배지는 3.3:1이었던 주황을 짙게 바꿔 6.0:1로 맞췄다.

## 직접 확인한 화면
홈(데스크톱/모바일/풀페이지, KO 모바일 풀페이지, 다크), 스크롤 위치별 스파이 동작(논문·연락처 위치에서 현재 표시가 맞게 바뀜), 모바일 전체 메뉴, 논문 상세(데스크톱 스크롤 상태, KO 모바일), 연구 상세(다크), 뉴스 상세(다크 풀페이지), 연락처(KO 모바일, 현재 칩 자동 노출).

고친 것:
- 데스크톱에서 연구실명이 말줄임되던 문제(메뉴 전환 폭을 1240px로 조정)
- 목차 행의 세로 정렬
- 연구 카드 빈칸(5개 + "전체 보기" 타일)
- 연락처 2열 배치
- 한글 이니셜("예구" → "예")
- 다크 모드에서 지나치게 밝던 타일

## 남은 문제
- 섹션 사이 여백이 커서 모바일 홈 전체 길이가 약 11,700px이다. 원하면 `.sec` padding만 줄이면 된다.
- 홈 바의 "홈" 항목은 정적으로 `aria-current="page"`이고, 스크롤하면 JS가 `location`으로 바꾼다. JS가 없으면 섹션 표시만 빠지고 링크는 그대로 동작한다.
- 테마 고유 문구를 템플릿 안에서 처리함 → i18n.yaml 추가 제안:
  - `common.skip`: Skip to content / 본문 바로가기
  - `common.top`: Top / 맨 위로
  - `common.sections`: Sections / 섹션
  - `home.on_this_page`: On this page / 이 페이지의 구성
  - `pubs.years`: Years / 연도

## 공통 코드 제안(고치지 않음)
1. `shared.js`의 메뉴 토글에 "링크 클릭/Esc로 닫기"와 "열렸을 때 본문 스크롤 잠금"이 없다. 이 테마는 `onepage.js`에서 처리했다. 공통으로 넣으면 모든 테마의 모바일 메뉴가 좋아진다.
2. `m.year_index`에 `data-spy` 같은 훅이 없어 이 테마는 연도 바를 직접 마크업했다. 매크로에 `attrs` 인자를 두면 재사용할 수 있다.
3. `initials_of` 한글 처리, `pub_item` id 중복, 제목의 `CO <sub>2</sub>` 공백, `shot.mjs --full`의 lazy 이미지 문제는 `reports/themes/t3_ocean.md` 공통 제안과 같다.
