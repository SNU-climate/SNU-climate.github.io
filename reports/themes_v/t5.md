## v02 — 확장판 (`themes/t5.v02/`)

v01을 그대로 복사한 뒤 리뷰의 v02 방향 중 데이터가 있는 3가지 + 이를 잇는 탭 1가지를 구현했다. 외부 라이브러리 없음(인라인 SVG + 작은 `assets/issues.js`, file://에서 동작, CDN·외부 API 없음).
`theme.yaml`: title "Science Magazine v02", `extra_pages: [about, gallery, issues, journals]`, `pi_page: true`. 메뉴에 Issues(연간호) 추가.

### 새 기능
1. **연간 "Issue" 아카이브** (`issues.html`, 리뷰 v02 1번)
   - 2000~2026 27개 연도를 잡지 표지로 자동 생성: 마스트 "CSL", "Vol. N"(첫 논문 연도 = 1호), 큰 연도, 대표 논문(그해 `featured` 논문, 없으면 가장 최근 논문)의 학술지·제목, 논문 수.
   - 표지 그림: 그해 논문에 연결된 연구 그림(`research.figures[].pub.year`, 2022·2021·2020·2015) → 그해 포토 에세이 표지(2014~2025) → 없으면 글자 표지(연도별 논문 수 막대 `stats.per_year_full`, 그해 금색 강조). 규칙은 페이지에 적어 둠.
   - 표지를 누르면 그해 "연간호" 하나가 보인다(`#issue-YYYY`, `issues.js`가 나머지를 숨김; JS가 없으면 모든 호가 차례로 보임): 큰 표지, 논문·뉴스·포토 에세이·영상 수, 대표 논문(저자·DOI·목록 번호), 그해 학술지 상위 4, 이전/다음 호, 차례(그해 논문 전체 → `publications.html#pub-N`), 그해 뉴스·앨범·영상.
   - 연도별 별도 페이지는 빌드 지원이 필요해서 한 페이지 + 앵커로 만들었다(빌드 수정 없음). 모바일은 표지 진열대가 가로 스크롤이고 고른 표지로 진열대만 밀린다.
   - 홈에 "Back issues" 띠(최근 6호 표지 → 해당 호).
2. **저널 데스크** (`journals.html`, 리뷰 v02 2번): `stats.top_journals` 10곳마다 총 편수, 2000~2026 연도별 게재 막대, 첫 게재 연도, 최신 3편(DOI·목록 번호), `<details>`로 그 학술지 논문 전체. 아래에 전체 45개 학술지(편수 순·첫 게재 연도). 홈 "From the journals" 머리에 링크.
3. **Watch & Read** (`videos.html`, 리뷰 v02 4번): 영상 설명의 DOI로 논문이 연결된 6편을 "영상 + 논문 카드"로 짝지음(학술지·연도·제목·저자·서지, "논문 보기"·"목록 № N", 같은 영상을 쓴 뉴스 글 링크). 나머지 9편은 아래 격자. 초록은 데이터에 없어 넣지 않았다.
4. **논문 탭**: Publications · Journal desk · Annual issues 세 보기를 잇는 탭(건수 표시). 저널 데스크는 메뉴에서 Publications 아래로 표시.
- 하지 않은 것: 리뷰 v02 3번 "Explainer 기사"는 `research.yaml`의 `explainer` 문단이 없어 만들지 않았다(지어내지 않음). 4번의 초록도 같은 이유.
- 추가 페이지의 `<title>`은 i18n에 `nav.issues/journals`가 없어 템플릿에서 `page_title`을 정했다("Annual issues | …", "연간호 | 기후시스템연구실").

### 남은 문제
- 대표 논문 규칙이 기계적이다(featured가 있는 해는 2017·2020·2022·2024뿐, 나머지는 "가장 최근 논문"). 교수님이 고른 논문을 쓰려면 데이터에 `cover: true` 같은 필드나 `issues.yaml`이 필요하다(제안).

- JS가 꺼진 환경에서는 27개 호가 모두 펼쳐져 페이지가 길다(기능은 유지).
- 메뉴 9개(Issues 추가). v01과 같은 커버 그림(콘텐츠) 문제가 그대로 있다.
- 공통 제안: 연도별 연간호 페이지를 따로 만들려면 build.py에 "연도별 페이지 생성"(예: `year_pages: issue`) 지원이 필요하다.
