### 선택 기능 (리뷰 판단 그대로)
- **구성원 개인 페이지 `member.html`**: 사용. 45명 + 교수 1명. 사진, 직위, 이메일(`@` 앞 줄바꿈), 홈페이지, 관심 분야 칩, 학력·경력·수상(교수는 봉사·학회 회원까지), 참여 논문 목록(번호 → 논문 페이지 앵커). 브레드크럼과 "구성원 목록" 복귀가 해당 역할 섹션으로 돌아간다.
- **연구 주제 페이지 `research_topic.html`**: 사용. 큰 지구본이 그 주제 지역들의 구면 중심으로 돌아 있고, 지역 이름 버튼을 누르면 그 지역으로 회전하며 1.8배 확대된다(원형 렌즈 안에서만 보이게 잘라 구 밖으로 나오지 않음, 점선 렌즈 테). 본문 전체, 주요 연구 주제(`themes`), 연구 하이라이트(`figures` + 설명 + 연결 논문 번호), 주요 논문, 관련 영상, 이전/다음 주제. `research.html`은 개요(요약 앞부분, 주제 칩, 논문·그림·영상 건수, 미니 지구본, 자세히 보기)로 줄였다.
- **갤러리 `gallery.html`**: 사용. 연도 묶음 + 연도 바로가기, 4:3 표지 카드에 사진 장수 배지. 모바일 2열. 앨범 상세는 사진을 4:3으로 맞춰 격자로 보인다.

### 남은 문제
- 홈 뉴스 리드와 썸네일 행에 대표 뉴스의 한글 자막 유튜브 썸네일(`content/news/2026-10-23-permafrost-soil-moisture/cover.jpg`)이 그대로 나온다. 리뷰 3-2의 콘텐츠 교체가 필요하다.
- 다크 고정(`color-scheme: dark`)이다. 공식 홈페이지로 괜찮은지 교수님 확인이 필요하다.
- 지구본 vendor JS 약 120KB(d3-array·d3-geo·topojson·Natural Earth)를 홈·연구 페이지에서 불러온다.
- 연구 개요의 미니 지구본은 지역이 넓게 흩어진 주제(기후변화 메커니즘: 북극·열대 대서양·서태평양)에서 한두 지역이 지평선 너머로 숨는다. 이름은 칩으로 모두 보인다.
- 졸업생 4명의 학위·연도 누락, 구성원 `pub_name` 22명 중 11명(참여 논문 자동 연결에 필요)은 데이터 문제다.
- 1차 경미 15(모바일 글자 간격 불균일)는 실기기에서 확인해야 한다.

## t8.v02 — 확장판 (v01 + 기능 4개)

v01의 모든 수정을 그대로 포함한다. 새 기능은 실제 컨텍스트 데이터(`research.regions`·`region_names`·`pubs`·`video_items`, `stats.per_year_full`, `pubs_by_year`)와 방문자의 현재 시각만 쓴다. 외부 라이브러리는 v01과 같은 vendor 파일뿐이고 런타임 CDN·외부 API는 없다(웹폰트 제외, 규약 4-9).

### 새 기능
1. **연구 지역 영역 + 탐색 카드(홈)** — 리뷰 v02 "연구 영역 지구본"에 대응.
   - 각 연구 지역을 반경 7°의 반투명 원(주제 색, 점선 테두리)으로 칠한다. 지구본의 지역이나 범례를 누르면 범례 자리에 탐색 카드가 열린다. 카드 내용: 주제 번호·색, 지금 보는 지역 이름, 주제 제목(주제 페이지 링크), 지역 전환 버튼(누르면 지구본이 그 지역으로 회전), 요약, 주요 논문 2편(번호 → 논문 페이지 앵커), "자세히 보기" 버튼, 논문·영상 건수.
   - 카드가 아래를 덮으므로 고른 지역이 지구본 위쪽에 오게 돌린다. 열려 있는 동안 자동 회전을 멈추고, 다른 주제 원은 흐리게 한다.
   - 닫기 버튼(44px), Esc로 닫는다. 키보드로 열면 카드 제목에 포커스가 가고, 닫으면 연 요소로 돌아간다. 열려 있는 동안 범례에는 `inert`를 건다. JS가 없으면 범례·마커가 주제 페이지 링크로 동작한다.
   - `templates/index.html`(`[data-explore]`, `.xp`), `assets/globe.js`(`caps`, `openCard`/`closeCard`/`pick`).
2. **실시간 밤 표시(홈)**
   - 태양 직하점(NOAA 근사식, 오차 1° 미만)의 대척점을 중심으로 반구(90°)와 안쪽 띠(84°)를 어둡게 칠해, 지금 밤인 지역을 보인다. 1분마다 갱신한다.
   - 지구본 아래 안내에 "어두운 쪽: 지금 밤인 지역 UTC hh:mm"을 표시한다. 시각은 방문자 기기 시계를 쓴다.
   - `globe.js` `subsolar()`, `.g-night`.
3. **논문 타임라인(홈 "최근 논문" 섹션을 대체) + 연도 막대 레일(논문 페이지)** — 리뷰 v02 "논문 시간 슬라이더"를 데이터 범위 안에서 구현.
   - 2000–2026 연도별 편수 막대 27개는 서버에서 그린다(최대 29편 기준 높이). 슬라이더(`input[type=range]`, 접근 이름 "연도"), 재생/정지 버튼, 막대 클릭으로 연도를 고른다. 고른 해의 편수, 누적 편수, 주요 학술지 3개(편수), 논문 4편, "그해 전체 논문 → `publications.html#yYYYY`"를 보인다.
   - 재생은 0.9초 간격이고, 재생 중에는 `aria-live`를 끈다. JS가 없으면 최신 연도 패널만 보인다.
   - 논문 페이지 데스크톱 연도 레일에는 편수에 비례한 막대를 붙였다.
   - `index.html` `[data-timeline]`, `globe.js` `initTimeline()`, `_ui.html pub_page`(`.yr-bar`).
4. **연구 지역 둘러보기(연구 주제 페이지)** — 리뷰 v02 "논문 그림 투어"의 대안.
   - 그림별 좌표 데이터가 없어서, 그림 대신 주제의 연구 지역을 차례로 돈다. "지역 차례로 보기" 버튼을 누르면 3초마다 다음 지역으로 회전·확대하고, 지역 이름 캡션을 바꾼다. 지역 원도 함께 표시한다.
   - 지구본을 드래그하거나 방향키를 누르거나 지역 버튼을 누르면 멈춘다. 지역이 1개뿐이거나 동작 줄이기 설정이면 버튼을 숨긴다.
   - `research_topic.html` `[data-tour]`, `globe.js` `setTour()`.

### 남은 문제
- 지역 원은 `regions` 점 좌표를 중심으로 그린 표시일 뿐 실제 연구 영역 경계가 아니다. Niño3.4 상자·북극권 같은 실제 영역은 `research.yaml`에 `areas: [{name{en,ko}, bbox|polygon}]`가 필요하다(데이터 수정 범위 밖이라 제안만 함). 지금은 `globe.js`의 `caps: 7`만 바꾸면 된다.
- 리뷰 v02의 "연구실 활동 지도"는 뉴스·앨범에 장소 좌표(`location{name,lat,lon}`)가 없어서 구현하지 않았다. 타임라인도 논문별 주제·영역 태그가 없어서 주제 흐름(엘니뇨 → 북극 → 탄소순환)을 보여 주지 못하고, 연도별 편수·학술지·논문만 보인다.
- 모바일에서는 탐색 카드(약 480px)가 지구본 대부분을 덮는다. 고른 지역은 위쪽 띠에 보인다.
- 타임라인 막대 버튼은 마우스·터치 전용이고(`tabindex=-1`), 키보드는 슬라이더로 조작한다. 모바일에서 막대 폭은 약 11px다.
- 밤 표시는 방문자 기기 시계를 쓰고, 캡처 시점마다 모양이 달라진다.
- 영역 색조에 `color-mix()`를 쓴다. 지원하지 않는 오래된 브라우저에서는 색조만 빠진다.
- v01의 남은 문제(한글 썸네일, 다크 고정, vendor JS 120KB)가 그대로 남아 있다.

## 공통 빌드에 대한 제안 (고치지 않음)
- `research.yaml`에 `areas`(영역 다각형), 뉴스·앨범 front matter에 `location`, 연구 `figures`에 `center[lat,lon]`을 두면 v02의 영역 지구본·활동 지도·그림 투어를 실데이터로 완성할 수 있다.
- i18n에 `common.close`, `common.play`, `common.pause`가 있으면 테마 문구 사전 `S`의 항목을 줄일 수 있다.
