## t1.v02 — 확장판 (v01 + 리뷰 v02 방향)

**theme.yaml**: `title: "Classic Academic v02"`, `extra_pages: [gallery, history]`, `pi_page: true`, 테마 고유 문구 `strings`(EN/KO, 템플릿에서 `tr(theme.strings.키)`; i18n.yaml은 고치지 않음). 외부 라이브러리 없음(테마 JS `assets/t1.js`만).

### 새 기능
1. **연혁(History) 페이지** — 리뷰 v02 ① 연구실 연혁. `history.html`, 메뉴에 People 뒤 "History/연혁" 추가, `<title>`도 테마 문구로 덮어씀.
   - 한눈에 보기: 논문 318, 활동 기간 2000–2026, 최다 연도 2024(29편), 졸업생 23, 뉴스 99, 사진 앨범 89(모두 `stats`).
   - 연도별 논문 수 막대(`stats.per_year_full`, 최다 연도 금색). 막대를 누르면 그 연도로 이동해 연간 기록을 연다.
   - 연대기 1998–2026: 연도마다 논문 수 막대 + 이정표 — 교수 학력·경력·수상(`pi.education/career/awards`), 졸업생(학위별, 개인 페이지 링크), 논문 번호 이정표(1·100·200·300번째 논문, `p.num`), 대표 논문(`selected_pubs`), 수상·논문 출판·행사·연구실 소식(`news_items`). 데이터에 없는 milestone은 만들지 않았다.
2. **연도별 연간 기록 아카이브** — 리뷰 v02 ②. 연대기의 각 연도에 `<details>` "연간 기록": 그해 논문 전체(번호→논문 목록 앵커), 소식, 영상(`videos.published`), 사진 앨범 썸네일. 한 페이지 + 앵커(`#yrYYYY`) 방식이라 빌드 지원 없이 동작. 왼쪽 sticky 연도 색인, 모두 펼치기/접기, URL 해시로 진입하면 자동 펼침. JS가 없어도 최신 연도는 펼쳐져 있고 나머지는 클릭으로 열림.
3. **졸업생 진로 표** — 리뷰 v02 ④. 구성원 페이지 졸업생 절을 학위별 집계(Ph.D. 10 · M.S. 5 · Postdoc 3 · Researcher 1 · 기록 없음 4) + 공식 표(사진·이름·다른 언어 이름 / 학위·직위 / 연도 / 현재 진로)로. 비어 있는 값은 "—". 모바일은 카드형 행.
4. **배너의 실제 연구 그림** — 리뷰 v02 ③을 데이터 범위 안에서 대체. 등치선 SVG를 새로 만들 데이터가 빌드 컨텍스트에 없어서, 대신 홈 배너 오른쪽에 `research.figures`의 원본 그림을 주제마다 1장(연결 논문이 있는 그림 우선, 5장) 액자로 싣고 주제·설명·논문 번호(목록 앵커)를 단다. 이전/다음 버튼(자동 전환 없음, `aria-live` 카운터). 1000px 이하에서는 숨김.
- 부가: 구성원 개인 페이지 연결을 켰다(`m.member_card`, 졸업생 표 이름 링크). 홈 "최근 논문" 위에 작은 연도별 막대 → 연혁 링크. 배너 두 번째 버튼은 연혁.

### 남은 문제
- 연혁 페이지가 길다(데스크톱 약 8,500px, 2026년 기록이 펼쳐진 상태). 연간 기록은 논문 목록과 내용이 겹친다(의도된 연도별 재구성).
- 교수 경력은 시작 연도로만 배치해 2013년에 4건이 몰린다. 연구실 주요 사건(POSTECH→SNU 이전 등)은 `pi.career`로만 보이며, 별도 milestones 데이터는 없다.
- 졸업생 연도·학위가 없는 4명과 현직이 없는 20명은 표에 "—"로 나오고 연대기에는 빠진다(콘텐츠 보완 필요).
- 개인 페이지 연결을 켜서 관심 분야·논문 연결이 없는 구성원(리뷰 지적: 관심 분야 16/22, pub_name 11/22)은 페이지가 얇다.
- 배너 그림은 흰 바탕 원본 논문 그림이라 액자 안에서 글자가 작다(클릭하면 주제 페이지로 이동). 리뷰가 제안한 "실제 등치선 SVG"는 오프라인 데이터 처리가 필요해 만들지 않았다.
- `--full` 캡처에서 lazy 이미지(졸업생 표 아래쪽 사진 등)가 빈 원으로 찍히는 것은 캡처 도구 문제(리뷰 3-6절)로, 실제 화면에서는 로드된다.
