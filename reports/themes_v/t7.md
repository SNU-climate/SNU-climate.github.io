## t7.v02 — 확장판 (v01 + 기능 4개)

`theme.yaml`: `title: "One-page Scroll v02"`, palette에 영상 빨강(#e62117) 추가, `extra_pages: [gallery]`, `pi_page: true`. 외부 라이브러리는 쓰지 않았다(막대그래프는 빌드 때 인라인 SVG, 동작은 `onepage.js`). 런타임 CDN·외부 API 없음.

### 새 기능

1. **목차 = 연구실 현황판**(리뷰 v02 ①): 히어로 오른쪽 목차 카드 위에 어두운 현황판을 두었다. `stats.per_year_full`로 그린 2000–2026 연도별 논문 막대(최다 연도는 밝게, 최근 연도는 주황, 막대마다 `<title>` 툴팁, 누르면 논문 페이지), 논문 수 318, `stats.top_journals` 상위 3개(Climate Dynamics 53 / J. Climate 36 / GRL 35)와 비율 막대. 목차 항목마다 보조 줄을 붙였다: 논문·뉴스·갤러리·영상은 "Latest · 날짜"(`pubs[0]`, `news[0]`, `albums[0]`, 영상 최신 게시일), 구성원은 "Alumni 23", 연구는 "13 figures", 연락처는 "Bldg. 501, Rm. 522". 모두 빌드 컨텍스트 값이다.
2. **Watch the paper**(리뷰 v02 ③): `videos[].pub`(설명란 DOI로 연결된 영상 6편)을 영상 + 논문 카드 한 쌍으로 묶었다. 영상은 `yt_html()`(클릭해야 iframe 로드), 논문은 번호·학술지·제목(DOI 링크)·저자, 버튼은 "Paper N →"(논문 목록 앵커)과 같은 영상을 쓴 뉴스가 있으면 "News →". 홈 Videos 섹션 맨 위에 가로 스크롤 띠(스냅)로, 영상 페이지 맨 위에 2열 그리드(`#watch-<영상ID>` 앵커)로 넣었다. 홈 아래의 영상 3편은 쌍이 없는 영상으로 채워 중복을 없앴다.
3. **연구 주제 스크롤 스토리**(리뷰 v02 ②): 연구 페이지의 각 주제를 "개요(요약 + 연구 주제 칩) → 그림 2 → 그림 3 …" 단계로 나누고, 넓은 화면(980px 이상, JS 있을 때)에서는 오른쪽에 고정된 그림판이 화면 가운데에 온 단계의 그림으로 바뀐다(IntersectionObserver, 크로스페이드, 진행 점). 단계에는 데이터에 있는 캡션과 연결 논문(번호·학술지·제목)만 붙였다. 리뷰가 말한 "그림별 1~2문장 설명"은 데이터에 없어서 지어내지 않았다. 좁은 화면이나 JS가 없을 때는 각 단계 바로 아래에 그림이 나온다. `.topic`의 `overflow:hidden`이 sticky를 막아서 스토리 섹션은 `overflow: clip`으로 바꿨다.
4. **논문 목록의 ▶ Video 링크**(②의 연장): 빌드 때 `videos[].pub`로 `{논문 번호: 영상 페이지 앵커}` JSON(`#pub-videos`)을 만들고, `onepage.js`가 `#pub-N`이 있는 페이지(홈 최근 논문, 논문 페이지)에 "▶ Video" 배지를 붙인다(예: 310번 Earth's Future 2026).

리뷰 v02 ④(소식 타임라인)는 하지 않았다. v01에서 뉴스·갤러리 분리와 연도·분류 필터를 이미 넣었고, 위 네 기능이 "한 장으로 보는 연구실" 콘셉트를 더 직접 밀어준다고 판단했다.

## 남은 문제
- **데이터 쪽(테마 밖)**: 대표 뉴스 표지(`2026-10-23-permafrost-soil-moisture/cover.jpg`)에 한글 자막이 있어 영문 홈 뉴스 대표 카드와 v02 Watch the paper 첫 카드에 그대로 나온다. 영상 제목이 국문뿐이라 영문 페이지에도 국문으로 나온다. 졸업생 4명은 학위·연도가 없어 이름만 나온다. 연구 figures 가운데 캡션 없는 그림 4장(biogeochemical 1, modeling 3)은 v02 스토리 단계에 "그림 n" 표시만 나온다.
- **테마 고유 문구**: v02의 `Papers per year`, `Top journals`, `Watch the paper`와 그 설명, `Overview`, `Figure`, `Latest`, `{n} figures`, 스토리 안내문은 `i18n.yaml`에 키가 없어서 `t7.v02/templates/_op.html`의 `L` 사전(EN/KO)에 두었다. 이 테마를 고르면 `i18n.yaml`로 옮기는 것을 제안한다(`home.per_year`, `home.top_journals`, `videos.watch`, `videos.watch_lead`, `research.overview`, `research.figure`).
- v02 스크롤 스토리의 sticky는 `overflow: clip`에 기댄다(Chrome 90+, Safari 16+). 그보다 오래된 브라우저에서는 그림판이 고정되지 않고 주제 맨 위에 머문다(그림 전환은 그대로 동작).
- 모바일 홈은 칩 줄이 보일 때 상단 고정 124px, 아래로 스크롤하면 61px이다. 앵커로 이동하면 칩 줄 높이만큼 여백이 더 생긴다(가림은 없음).
- `shot.mjs --full`로 찍은 긴 캡처에서 lazy 이미지 일부가 빈칸으로 나온다(리뷰 3-6의 도구 문제). 섹션 캡처는 스크래치패드 스크립트로 lazy를 풀고 다시 찍어 확인했다.
- 1차 리뷰 경미 15("20 26" 글자 간격)는 headless DPR2 캡처에서 영문 칩·태그 일부에 여전히 보인다. 실기기 확인이 필요하다.
